     6→//
     7→// Global conventions (Constitution v1.1 §5, ERD v1.1 §2):
     8→//   * Primary keys:        `String @id @default(cuid())` (cuid is time-ordered)
     9→//   * Audit columns:       `createdAt DateTime @default(now())` + `updatedAt DateTime @updatedAt`
    10→//   * Soft delete:         `deletedAt DateTime?` on all updatable aggregates
    11→//   * Optimistic currency: `version Int @default(1)` on BoQDocument, BoQSection,
    12→//                          BoQItem, Project, RateAnalysis, CalculationRecord,
    13→//                          ItemLibrary, CompanyProfile, UserSettings, Subscription
    14→//   * Money & quantities:  `String` storing decimal strings — application layer
    15→//                          uses decimal.js; SQLite has no native decimal type
    16→//   * Bilingual content:   `<field>En String` + `<field>Ar String?` (never concatenated)
    17→//   * Audit logging:       every mutation writes a row to AuditLog (append-only)
    18→//
    19→// Phase 1 (BoQ module) tables are complete and enforced.
    20→// Phase 2-4 tables are declared in §8 below as RESERVED additive (declared,
    21→// not enforced in Phase 1) so the schema never needs to be rewritten.
    22→// =============================================================================

   293→// AuditLog: append-only, no updates, no deletes (enforced by application layer).
   294→// Every mutation in the system writes a row here per BR-WEB-6.
   295→model AuditLog {
   296→  id          String   @id @default(cuid())
   297→  actorUserId String?  // null for system actions
   298→  action      String   // "create" | "update" | "delete" | "restore" | "import" | "export"
   299→  entityType  String   // "Project" | "BoQDocument" | "BoQItem" | ...
   300→  entityId    String
   301→  beforeJson  String?  // JSON snapshot of row before mutation
   302→  afterJson   String?  // JSON snapshot of row after mutation
   303→  ipAddress   String?
   304→  userAgent   String?
   305→  createdAt   DateTime @default(now())
   306→
   307→  actor User? @relation(fields: [actorUserId], references: [id], onDelete: SetNull)
   308→
   309→  @@index([actorUserId, createdAt])
   310→  @@index([entityType, entityId])
   311→  @@index([createdAt])

   590→  createdAt    DateTime  @default(now())
   591→  updatedAt    DateTime  @updatedAt

   593→  boqItem BoQItem?          @relation(fields: [boqItemId], references: [id], onDelete: Cascade)
