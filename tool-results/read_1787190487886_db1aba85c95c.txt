     6→     6→//
     7→     7→// Global conventions (Constitution v1.1 §5, ERD v1.1 §2):
     8→     8→//   * Primary keys:        `String @id @default(cuid())` (cuid is time-ordered)
     9→     9→//   * Audit columns:       `createdAt DateTime @default(now())` + `updatedAt DateTime @updatedAt`
    10→    10→//   * Soft delete:         `deletedAt DateTime?` on all updatable aggregates
    11→    11→//   * Optimistic currency: `version Int @default(1)` on BoQDocument, BoQSection,
    12→    12→//                          BoQItem, Project, RateAnalysis, CalculationRecord,
    13→    13→//                          ItemLibrary, CompanyProfile, UserSettings, Subscription
    14→    14→//   * Money & quantities:  `String` storing decimal strings — application layer
    15→    15→//                          uses decimal.js; SQLite has no native decimal type
    16→    16→//   * Bilingual content:   `<field>En String` + `<field>Ar String?` (never concatenated)
    17→    17→//   * Audit logging:       every mutation writes a row to AuditLog (append-only)
    18→    18→//
    19→    19→// Phase 1 (BoQ module) tables are complete and enforced.
    20→    20→// Phase 2-4 tables are declared in §8 below as RESERVED additive (declared,
    21→    21→// not enforced in Phase 1) so the schema never needs to be rewritten.
